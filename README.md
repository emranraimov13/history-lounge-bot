# History Lounge — Telegram-бот отзывов

Бот **@loungeHistory_bot**: приветствие с картинкой, оценка от 1 до 5,
текстовый отзыв, админ-панель со статистикой и экспортом в CSV.

## Быстрый запуск

```bash
cd ~/Desktop/history-lounge-bot
./run.command
```

Или двойным кликом по `run.command` в Finder. Окно терминала должно
оставаться открытым — пока оно открыто, бот работает.

Проверка: откройте [@loungeHistory_bot](https://t.me/loungeHistory_bot)
и нажмите «Запустить».

## Что уже настроено

- Токен лежит в `.env` (файл не попадёт в git).
- Приветствие, картинка `assets/welcome.jpg`, меню и кнопки.
- Отзывы сохраняются в `data/reviews.db`, дублируются админам в Telegram.
- Статистика, список отзывов и экспорт CSV — в `/admin`.
- Ссылка на сайт, меню, акции и бонусную программу — кнопка «🌐 Сайт»
  в меню и команда `/site`.
- Имя бота — **History отзывы**, описание и список команд
  устанавливаются при запуске автоматически.

Имя можно поменять в `bot/config.py` (`BOT_NAME`) или через `.env`:

```env
BOT_NAME=History отзывы
```

Username (`@loungeHistory_bot`) меняется только в @BotFather командой `/setusername`.

## Сайт ресторана

Официальный сайт — [historylounge.app](https://historylounge.app).

- Кнопка «🌐 Сайт» в главном меню сразу открывает сайт.
- Команда `/site` показывает, что есть на сайте: меню с ценами, акции,
  бонусная программа с кэшбэком 5–15% и личный кабинет.
- В разделе «О ресторане» есть ссылка на сайт и кнопки «Меню и цены»,
  «Бонусы».

Ссылки задаются в `bot/config.py` в блоке `RESTAURANT`:
`site_url`, `site_menu_url`, `site_promotions_url`, `site_loyalty_url`,
`site_account_url`.

## Админ-доступ

1. Откройте бота и отправьте `/myid` — он покажет ваш Telegram ID.
2. Впишите его в `.env`:

```env
ADMIN_IDS=123456789
```

Несколько админов — через запятую: `ADMIN_IDS=123456789,987654321`.

3. Перезапустите бота (закройте терминал и запустите `run.command` снова).
4. Отправьте `/admin` — появится панель.

## Как заменить приветственную картинку

В боте: `/admin` → **🖼 Заменить картинку** → отправьте фото.
Бот сохранит его, покажет при входе (`/start`) и автоматически поставит
на аватарку.

Оригинал текущей картинки лежит в `assets/welcome_original.png`,
рабочая версия для бота — `assets/welcome.jpg` (1080×1080).

## VIP-карты

### Премиальная версия

Именная карта для гостей со статусом VIP — при расходах от
**25 000 000 сум**. В дизайне: почти чёрный оливковый металл, золотая
фольга, крупный фирменный знак **History**, круглая печать клуба с
монограммой **HL** и минимальный набор данных владельца. Сумма
25 000 000 на самой карте не печатается — это критерий получения,
а не элемент дизайна.

| Файл | Назначение |
|---|---|
| `assets/vip_card_premium_print.pdf` | Печать: 2 страницы, CR80 85.6×54 мм, вылеты 3 мм, 600 dpi |
| `assets/vip_card_premium_front.png` | Лицо карты, 600 dpi |
| `assets/vip_card_premium_back.png` | Оборот карты, 600 dpi |
| `assets/vip_card_premium_mockup.jpg` | Макет для согласования |

На обороте — 4 привилегии: персональный менеджер, приоритетная бронь,
комплимент от шефа и закрытые мероприятия. QR ведёт на бота. Имя
`А. КАРИМОВ` и номер `0001` — демонстрационные, их можно заменить.
Скругление карты — 3.18 мм (стандарт CR80).

Для производства: чёрный пластик или металл, золотая фольга/тиснение,
матирование soft-touch. При печати на пластике попросите типографию
оставить вылеты и проверить, что золото не уходит в обрез. Золото в PDF —
цветовой макет; для настоящей фольги типография делает отдельную плату
(spot-слой) по золотым элементам.

Пересобрать премиальную версию:

```bash
.venv/bin/python tools/make_vip_card_premium.py
```

## Тексты

Все сообщения — в `bot/texts.py`. Можно менять без знания Python,
главное не ломать HTML-теги `<b>`, `<i>`, `<code>`.

## Где лежат данные

| Что | Где |
|---|---|
| Отзывы | `data/reviews.db` (SQLite) |
| Лог | `data/bot.log` |
| Картинка | `assets/welcome.jpg` |

## Автозапуск (необязательно)

Чтобы бот работал после перезагрузки Mac, можно добавить LaunchAgent.
Проще всего — через программу `Lingon` или `launchd` с командой:

```bash
/Users/macbookairm2/Desktop/history-lounge-bot/.venv/bin/python -m bot.main
```

с рабочей папкой `/Users/macbookairm2/Desktop/history-lounge-bot`.

## Безопасность

Токен бота — это пароль. Не публикуйте `.env` и не отправляйте его в чаты.
Если токен утёк — @BotFather → `/revoke` → получите новый и замените в `.env`.
